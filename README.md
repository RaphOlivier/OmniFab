# Galerie visuelle d'OmniFab

Historique visuel de l'application, capture automatiquement par
 a chaque evolution du code poussee
sur  (scenarios Xvfb : accueil, atelier-2d, atelier-3d).

-  — un dossier par lot de code,
  nomme par la date du commit et son SHA court ; un INDEX.md
  par dossier renvoie au commit et au run.
- Les images sont ajoutees, jamais remplacees : l'historique
  complet de l'evolution visuelle se lit commit par commit.

La branche  reste la seule source de verite du code ;
cette branche ne contient que des captures.
