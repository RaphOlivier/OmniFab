## Leçons (complément ride 2)

- **Changement de sémantique ⇒ relire les tests qui encodent l'ancienne** : une assertion de position ABSOLUE dans un croquis ancré sous-déterminé dépend du choix de variété du solveur — préférer des assertions RELATIVES (distances, écarts) qui survivent aux changements de sémantique d'ancrage.
- **DogLeg distribue le déplacement sur toutes les inconnues libres** : ne jamais supposer « le point ancre reste à sa graine » dans une passe sans ancrage ; c'est exactement ce qui rend l'ancrage post-résolution nécessaire (bug B) et ce qui casse les positions absolues.
- Garder les passages de solveur ADDITIFS et CONDITIONNELS : un second passage inconditionnel sur un système convergé est un risque inutile pour tous les croquis non ancrés.
- Le `jq` de l'environnement : `-r` donne le texte brut, `-j` (non standard ici) réencode en JSON — extraire les textes dépôt des tool-results avec `jq -r`, pas `-j`, et couper le `\n` final parasite de `-r`.
- Les apostrophes des marqueurs de garde : le code Rust du projet utilise l'apostrophe DROITE `'` — trois gardes fausses ce jour venaient d'apostrophes courbes `’` collées dans mes marqueurs (leçon : copier-coller les marqueurs depuis le fichier, ne pas les retaper).

## Leçons (rides 13-14, complément)

- **Le repli ride-11 ne couvrait que le point déplacé** : une paire confondue qui ne le concerne pas (carré affaissé par deux orientations opposées) exige une réparation SYSTÉMATIQUE des graines de passe.
